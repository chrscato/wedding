# Wedding venue research

Venue notes, quotes analysis and cost estimators for the McManus-Cato wedding.

Site: https://chrscato.github.io/wedding/

- `hyatt_oakbrook/` – Hyatt Lodge Oak Brook notes and report source
- `makray_golf/` – Makray Memorial Golf Club notes and report source
- `docs/` – the published GitHub Pages site (generated)

After editing a report, run `python publish.py` and commit `docs/`.
Source PDFs are kept local and are not committed.
